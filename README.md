# API - Contribuição e Doação

API para processamento e armazenamento de doações e contribuições para familias da weplay.
## 📋 Funcionalidades

- Processamento do jsom contendo a doação
- Processamento do json contendo a contribuição
- Armazenamento em banco SQLite
- Sistema completo de logs em tempo real
- Endpoints para consulta de contribuição e doação

## 🚀 Instalação

1. Clone o repositório ou copie o código
2. Instale as dependências:

```bash
npm install express sequelize sqlite3 cors
